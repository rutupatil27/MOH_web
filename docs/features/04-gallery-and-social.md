# Gallery & Social

Gallery is photo-only for current scope. Use responsive/compressed images, lazy loading, meaningful alt text and thumbnails.

- **Public page:** square-cropped thumbnails in a dense grid (2 columns on phones, 3 on tablets, 4 on desktop); every seventh photo is a 2×2 feature tile. Selecting a photo opens the full, uncropped image in a viewer with previous/next, arrow keys, swipe on touch screens and Escape to close. The viewer loads a screen-sized file and preloads the photos either side.
- **Uploads:** the admin can choose many photos at once. Each is prepared in the browser (scaled to at most 2400px, HEIC → JPEG where the browser can read it) and uploaded one at a time with its own status. One description (alt text), caption, category and visibility apply to the batch; single photos can be refined afterwards. Any photo size is accepted; small photos are never enlarged.

Supported socials: Instagram and YouTube.

Prefer links/cards to official profiles over heavy embedded social feeds if embeds hurt performance.

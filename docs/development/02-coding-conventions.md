# Coding Conventions

Use clear names, small reusable functions, focused components, composition and no dead code.

React: separate data fetching from presentational components, handle loading/empty/error/success states.

Backend: validate writes, centralize errors, keep controllers thin, protect secrets.

Git commit prefixes: feat, fix, refactor, docs, chore.

Never commit .env, secrets, private keys or large generated build artifacts.

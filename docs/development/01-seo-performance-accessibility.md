# SEO, Performance & Accessibility

## SEO
Every public page: unique title, meta description, canonical where appropriate, semantic headings, clean URL, Open Graph, descriptive alt text. Add sitemap.xml, robots.txt and accurate structured data. Never add fake reviews/ratings.

## Local SEO
Use accurate academy name, Nashik location, contact information and actual course offerings.

## Performance
Optimize LCP image, lazy-load below-fold media, reserve image dimensions, minimize JS, split admin bundle, lazy-load 3D, avoid layout shift, compress media.

## Accessibility
Semantic HTML, keyboard use, focus states, contrast, labels, alt text and reduced motion.

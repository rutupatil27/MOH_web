# UX Principles

Primary visitor goals:
1. Understand the academy.
2. See courses and levels.
3. Understand the teaching approach.
4. Browse gallery.
5. Find location/contact information.
6. Submit an enquiry.

Recommended navigation: Home, About, Courses, Gallery, Contact, Enquire CTA.

Forms: clear labels, mobile-friendly, client/server validation, useful errors, success confirmation, minimum necessary fields.

Accessibility: semantic HTML, keyboard navigation, visible focus, alt text, labels, sufficient contrast, reduced-motion support, and no color-only communication.

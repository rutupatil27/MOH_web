# Design Direction

## Concept
**Premium Music Academy × Modern Editorial × Interactive Storytelling**

The supplied references contribute oversized typography, high-contrast dark layouts, instrument imagery, premium product/editorial composition, playful illustrations, organic shapes, retro poster influence, cinematic photography, and 3D visual storytelling.

Do not copy any reference literally. Synthesize them into one identity.

## Brand personality
Warm, confident, artistic, premium, welcoming, expressive, disciplined, performance-oriented.

Avoid childish, generic coaching-site, stock-template, or chaotic aesthetics.

## Visual rhythm
Suggested homepage rhythm: dark hero → warm ivory story → dark course showcase → light learning approach → dark/immersive gallery → light contact/enquiry → dark footer.

## Hero
Strong statement + concise supporting copy + primary CTA + memorable musical visual. Possible visual: optimized 3D music scene, instrument composition, cinematic photo, or subtle waveform. Never let the effect hide the content.

## Storytelling
The homepage should communicate: Discover → Learn → Practice → Perform → Grow.
Animation should support the story, not become the story.

# UI Do & Don't

## DO
- Use global black/ivory/gold palette.
- Use strong editorial headlines.
- Use high-quality instrument imagery.
- Use purposeful asymmetry and whitespace.
- Use subtle borders and consistent buttons.
- Use meaningful hover states.
- Use motion to explain or emphasize.
- Use real academy content.
- Reuse components.

## DON'T
- Don't use Piano.
- Don't advertise online classes yet.
- Don't show fees.
- Don't add testimonials.
- Don't add payments.
- Don't invent statistics, awards, teachers, reviews or claims.
- Don't use random colors, excessive gradients or glassmorphism.
- Don't overuse rounded cards, floating notes, parallax or shadows.
- Don't autoplay audio.
- Don't make animation necessary to understand content.

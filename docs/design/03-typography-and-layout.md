# Typography & Layout

Use an expressive display face for major headings and a highly readable sans-serif for body text. A restrained serif/script accent may be used sparingly.

Define tokens for display, H1–H4, body, small text, labels, navigation and buttons.

Layout rules:
- consistent max-width container
- generous whitespace
- documented spacing scale
- mix full-bleed visuals, editorial columns, asymmetric compositions and standard content blocks
- do not make every section a card grid

Responsive layouts must be intentionally designed for mobile, tablet, desktop and large desktop. Do not simply shrink desktop.

Mobile: preserve the primary CTA, keep typography expressive, simplify navigation, reduce decorative motion, and use lighter/static 3D when appropriate.
